# Project Case Study: Hospital Operations Performance Dashboard

- **Badge:** BI Dashboard & PostgreSQL
- **Tech Stack:** SQL, PostgreSQL, Power BI, DAX, Python, EDA
- **GitHub URL:** https://github.com/Ganeshpawar74/Hospital-Dashboard

## Problem Statement
Clinical operations face delays in emergency response, resource assignment, and patient processing due to isolated spreadsheets and data logs.

## Solution & System Architecture
A business intelligence dashboard and database model:
1. **Database Warehousing:** Designs relational schema scripts inside a **PostgreSQL** database.
2. **ETL Pipelines:** Cleans and processes logs using Python scripts.
3. **Data Modeling:** Establishes star schema relationships in **Power BI**.
4. **DAX Formulation:** Custom Power BI DAX measures to calculate metrics (admission delays, patient processing times).

## Metrics & Impact
- **Data Scale:** Modeled and analyzed **50,000+ patient processing logs**.
- **Reporting Optimization:** Sped up reporting cycles by **60%**, replacing manual spreadsheets.
- **Impact:** Offers real-time metrics visibility to clinical coordinators, helping optimize staff assignments.
